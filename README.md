# SCP: Containment Chaos

A mod where random events happen after a set amount of time based on difficulty, inspired by the GTA V Chaos Mod (https://www.gta5-mods.com/scripts/chaos-mod-v)

A pretty simple mod made in SCP: CB 1.3.12 made by the SCP-CB Community Preservation Project, planning to port this to 1.3.11

* SCP: CB 1.3.12 (https://store.steampowered.com/app/2178380/SCP__Containment_Breach/)

* SCP-CB Community Preservation Project (https://store.steampowered.com/search/?publisher=SCP-CB%20Community%20Preservation%20Project)
